# LLM 提示词技巧

好的提示词能显著提升大模型输出质量。

## 原则

- **明确角色**：告诉模型「你是谁」。
- **给出示例**：few-shot 比零样本更稳定。
- **约束输出格式**：要求 JSON / Markdown / 表格。
- **分步推理**：让模型先思考再回答。

## 示例

```
你是一名资深后端工程师。请用中文，分三步分析这段代码的性能瓶颈，最后给出优化建议。
```
